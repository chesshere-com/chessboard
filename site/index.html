A chessboard that gets out of your way.

Framework-agnostic TypeScript, no runtime dependencies, about 15 kB gzipped. Drag, click, premove, draw arrows, theme with CSS variables. It renders and collects input; you decide what is legal.

npm install @chesshere/chessboard

Read the docs Open the playground

You are white. Drag a piece, or click and click.

Zero dependencies

The core imports nothing, including any chess rules library. Pair it with chess.js, a server, or an engine.

Smooth by construction

Position updates are diffed and animated. Racing server moves converge instead of desyncing.

Premoves and touch

Premove geometry built in, with scroll-aware touch handling so boards in long pages stay usable.

Shapes

Arrows, circles, regions, glyphs, ghost pieces and effects, as plain JSON you can store.

Themeable

Every visual is a --cb-* custom property. 12 licensed piece sets included.

Optional Solid

A thin SolidJS wrapper plus player bars, clocks, captured material and navigation controls.

Replay with animation

Each step is a single board.set({ fen, lastMove }). The board diffs the two positions and animates the difference, including castling.

board.set({
  fen,
  lastMove: [from, to],
  check: inCheck,
});

Shapes

Two channels: your app's autoShapes and the user's own right-drag scribbles. Try drawing on the board; your shapes never disturb the app's.

board.setAutoShapes([
  { type: "arrow", from: "e2", to: "e4", brush: "green" },
  { type: "circle", square: "d5", brush: "red" },
]);

Piece sets and theme

Switch the piece set with one attribute and recolor the board with CSS variables.

<div data-cb-pieces="celtic"></div>

.board { --cb-light: #ebecd0; --cb-dark: #739552; }
